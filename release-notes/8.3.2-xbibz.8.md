# Mochy Xbibz 8.3.2-xbibz.8

Version code: 81. Android 7+; varian universal GMS mencakup Google Cast.

Mochy Xbibz: perbaikan pencarian, penghematan animasi latar, dan build release terverifikasi.

## UI dan animasi

- Indikator loading mengikuti pengaturan animasi aplikasi dan Android.
- Animasi dekoratif berhenti saat aplikasi berada di latar belakang.
- Loading pencarian gagal memiliki tombol Coba lagi dan hasil kosong ditampilkan dengan jelas.
- Tautan changelog memakai area klik dan informasi aksesibilitas yang sesuai.

## Perbaikan fitur

- Permintaan saran pencarian menunggu jeda mengetik 250 ms untuk mengurangi permintaan berulang.
- Pergantian filter membatalkan permintaan pencarian sebelumnya.
- Pagination mencegah permintaan bersamaan dan berhenti ketika token halaman berulang.
- Riwayat lagu per artis dibaca dalam transaksi Room agar data dan relasinya konsisten.
- Kapabilitas video yang tidak tersedia ditangani secara eksplisit dengan kebijakan fallback yang sama.

## Build dan validasi

- Versi dinaikkan menjadi 8.3.2-xbibz.8 (kode 81).
- Signing release mendukung APK Signature Scheme v2 dan v4 saja; v1 serta v3 dinonaktifkan beserta berkas .idsig.
- Plugin Protobuf diperbarui untuk mendukung DSL AGP 9.
- API deprecated dan null-check yang dinyatakan tidak perlu oleh compiler diperbarui.
- 170 unit test lulus pada validasi lokal; pengujian perangkat nyata dan pengukuran FPS belum dilakukan.

## Instalasi

Build memakai key release bawaan repository melalui secret `MOCHY_RELEASE_*`. Pipeline memeriksa fingerprint sertifikat terhadap `.github/release-certificate.sha256`, menolak signing v1/v3, serta memverifikasi v2 dan v4 beserta berkas `.idsig`. Keberhasilan verifikasi APK harus dilihat dari hasil workflow, bukan dari konfigurasi saja.
