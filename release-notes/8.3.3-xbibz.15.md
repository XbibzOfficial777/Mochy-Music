## Yang berubah

- Saklar **pembaruan pra-rilis** di pengaturan perilaku aplikasi dan di lembar pembaruan. Default **mati**: hanya rilis resmi. Saat **nyala**, aplikasi juga menawarkan rilis GitHub yang ditandai pra-rilis (bisa dipakai, belum resmi) selama masih ada APK yang cocok. Paket desktop tanpa APK tidak ditawarkan.
- Saat pra-rilis nyala, nama aplikasi menjadi **Mochy Xbibz (Beta)**. Rilis resmi ini tetap **Mochy Xbibz**.
- Nama pengembang fork menjadi **Xbibz Official777**.

## What changed

- A **pre-release updates** switch in app behaviour settings and on the update sheet. Default **off**: official releases only. When **on**, GitHub pre-releases with a matching APK are offered. Desktop packages without an APK are not.
- On the pre-release channel the app name is **Mochy Xbibz (Beta)**. This official build stays **Mochy Xbibz**.
- Fork developer name is **Xbibz Official777**.
