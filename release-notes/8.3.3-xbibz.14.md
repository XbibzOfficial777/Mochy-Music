# Mochy Xbibz 8.3.3-xbibz.14

<!--lang:id-->

Kode versi: 87. Android 7 ke atas.

## Yang berubah

- Ketukan **Grafik**, **Pita**, dan **EQ otomatis** memakai drop kaca yang sama dengan saklar **Musik / Video**: mengalir, sedikit terangkat, lalu mengendap. Saklar Musik / Video tidak diubah.
- Catatan pembaruan merender **tabel** sebagai kolom, bukan baris pipa mentah.
- Bahasa mengikuti pengaturan aplikasi. Indonesia tidak dicampur Inggris, dan sebaliknya.
- Pembaruan **mendeteksi perangkat** lalu mengunduh berkas yang cocok (64-bit atau 32-bit). Paket universal hanya cadangan.

## Pilih berkas yang mana

| Berkas | Untuk perangkat | Ukuran |
| --- | --- | --- |
| `arm64-v8a` | Ponsel Android 64-bit | paling kecil |
| `armeabi-v7a` | Ponsel Android 32-bit | kecil |
| `universal` | Jika ragu, atau untuk emulator | paling besar |

Aplikasi memilih sendiri saat pembaruan. Ketiganya memakai kunci rilis yang sama.

Version code: 87. Android 7 and up.

## What changed

- Tapping **Graph**, **Bands**, and **AutoEQ** uses the same glass drop as the **Music / Video** switch: it flows, lifts, then settles. Music / Video is unchanged.
- Update notes render **tables** as columns, not raw pipe characters.
- The app language is not mixed. Indonesian stays Indonesian; English stays English.
- Updates **detect the device** and download the matching package (64-bit or 32-bit). The universal package is only a fallback.

## Which package

| File | For | Size |
| --- | --- | --- |
| `arm64-v8a` | 64-bit Android phones | smallest |
| `armeabi-v7a` | 32-bit Android phones | small |
| `universal` | If unsure, or for emulators | largest |

The app picks this for you on update. All three use the same release key.
