# Mochy Xbibz Desktop 0.1.0 — pra-rilis

Ini **bukan** rilis Android resmi. `v8.3.3-xbibz.14` tetap rilis stabil di ponsel.

Pra-rilis = belum resmi, **bisa dipakai**. Cari dan putar lagu YouTube Music di Windows atau Linux. Fitur Android (equalizer, modul, TV, Music/Video) belum ada di sini.

Pengembang: **Xbibz Official Technology ID**.

## Unduh

| Berkas | Sistem |
| --- | --- |
| `Mochy-Xbibz-desktop-0.1.0-win-x64-setup.exe` | Windows 10/11 64-bit (pemasang) |
| `Mochy-Xbibz-desktop-0.1.0-linux-amd64.deb` | Debian, Ubuntu, Linux Mint 64-bit |

Windows SmartScreen mungkin menahan pemasang karena belum ditandatangani sertifikat Windows. Pilih “Informasi selengkapnya” lalu jalankan. Linux: `sudo apt install ./Mochy-Xbibz-desktop-0.1.0-linux-amd64.deb`

## Yang diuji di GitHub Actions

- Electron dibuka di **tampilan virtual Linux (Xvfb)** dan di **runner Windows**.
- Paket `.deb` dan `.exe` dibuat setelah smoke itu hijau.
- Emulator Android tetap di Linux (KVM). Runner Windows GitHub tidak punya KVM, jadi emulator Android tidak dijalankan di Windows.
